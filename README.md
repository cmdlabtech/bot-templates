# CMDLAB Cursor plugins

Cursor plugins from CMDLAB LLC. Each plugin lives in its own folder under `bot-plugins/` and is listed in [`.cursor-plugin/marketplace.json`](.cursor-plugin/marketplace.json).

[![Donate](https://img.shields.io/badge/Donate-cmdlab.tech-blue)](https://cmdlab.tech/donate)

## Plugins

| Plugin | Folder | What it does |
| --- | --- | --- |
| **bambu-lan-printer** (1.0.0) | [`bot-plugins/bambu-lan-printer`](bot-plugins/bambu-lan-printer) | Runs Bambu Lab 3D prints end to end over your home network with LAN Only Mode and Developer Mode: slice with the Bambu Studio CLI, upload, start on your confirmation, and monitor. No Bambu Cloud. |

See each plugin's README for install steps and requirements.
